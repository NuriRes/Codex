# Instagram Followers Console Script

Bu repo, masaüstü Instagram'da (profil > takipçiler penceresi) geliştirici konsoluna yapıştırılarak çalıştırılabilecek bir yardımcı script içerir.

## Dosyalar

- `instagram_follower_manager.js`: Takipçi listesine seçim kutusu ekler, seçilenleri tek tek **Kaldır/Remove** akışıyla çıkarmayı dener.

## Kullanım

1. Instagram'da kendi profilinizi açın.
2. **Takipçiler (Followers)** penceresini açın.
3. F12 ile Console sekmesini açın.
4. `instagram_follower_manager.js` içeriğini yapıştırın ve Enter'a basın.
5. Sağ altta açılan panelden:
   - `Listeyi Tara`
   - `Hepsini Seç` / `Seçimi Temizle`
   - `Seçilenleri Çıkar`

## Notlar

- Instagram arayüzü sık değiştiği için script gelecekte güncelleme gerektirebilir.
- Çok hızlı toplu işlem hesabınız için geçici kısıtlamaya yol açabilir; işlem aralığını yüksek tutun.
- Script sadece açık olan ve yüklenmiş satırlar için çalışır; aşağı kaydırarak daha fazla takipçi yükleyin.
